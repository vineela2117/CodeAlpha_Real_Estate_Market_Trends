# 🏠 Real Estate Market Trends Dashboard

## 📌 Project Overview

The Real Estate Market Trends Dashboard is an interactive Power BI project developed as part of the CodeAlpha Internship Program. This dashboard provides valuable insights into property prices, location-wise market performance, housing trends, and investment opportunities through dynamic visualizations and data-driven analytics.

## 🎯 Objectives

- Analyze property prices across different locations
- Identify market trends and investment opportunities
- Compare property types and housing demand
- Track average area, bedrooms, and pricing patterns
- Support data-driven real estate decision-making

## 📊 Dashboard Features

### Key Performance Indicators (KPIs)
- Total Properties
- Average Property Price
- Average Property Area
- Total Locations Covered

### Interactive Visualizations
- Property Prices by Location
- Property Type Distribution
- Price Trend Analysis
- Bedrooms vs Property Price Analysis
- Location-wise Market Insights
- Dynamic Filters and Slicers
